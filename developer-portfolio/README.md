# 🚀 Developer Portfolio & Frontend Showcase

A modern, responsive, and feature-rich developer portfolio website built to showcase technical projects, core skills, resume credentials, and professional contact links.

## ✨ Features
- **Semantic HTML5 Structure:** Clean layout using modern sections (Hero, About, Tech Stack, Featured Projects, Contact).
- **Responsive Design:** Mobile-first approach optimized using CSS Flexbox and CSS Grid for seamless viewing across all devices.
- **Dark / Light Theme Engine:** Built-in theme switcher using CSS custom properties (variables) with state persistence via `localStorage`.
- **Interactive Navigation:** Mobile hamburger menu with smooth-scrolling architecture.

## 🛠️ Tech Stack
- **HTML5** (Semantic markup)
- **CSS3 / Flexbox / CSS Grid** (Styling & Responsive Layouts)
- **JavaScript (ES6+)** (DOM Manipulation, Theme Toggle, Mobile Menu)
- **FontAwesome** (Icons)
- **Vercel** (Live Hosting)
